    flyball.core.units¶

    flyball.core.units.dimension ¶

    Dimensions, units and prefixes.

    A BaseDimension is irreducible: the seven of the SI, plus angle and solid angle. A Dimension is a product of their powers; two units convert only if theirs agree. A Unit is a magnitude on a dimension: a factor to the coherent base, and for absolute scales a zero. Values in the framework are bare floats in a canonical unit; conversion happens at the edges.

    Unit dataclass ¶

    A magnitude on a dimension.

    factor takes a value to the coherent base unit; zero is the base-unit value at this unit's 0, non-zero only for absolute scales (°C, °F). Intervals and composed units ignore zero: a rise of 5 °C is 5 K. The quantity decides which conversion applies. scale is the full scale a UI shows by default, in this unit, when a signal says nothing of its own: 0-1 for One, 0-100 for Percent, 0-360 for Degree; None for a unit with no natural one (metres). A default for display, never a bound.

    quantity ¶

    quantity(name: str | None = None) -> Quantity

    A Quantity in this unit.

    name defaults to the dimension's name, lower-cased: Celsius.quantity() is Quantity("temperature", Celsius). A unit on a dimension nobody has named (a composed W/m² before Irradiance was declared) has no default, so the name must be given.

    Type Description

    No name given and the dimension has none.

    flyball.core.units.types ¶

    Annotating a float with the unit it is reported in.

    Measured(Celsius) is a float plus a UnitRef in its Annotated metadata. Pydantic puts the unit in the JSON schema; unit_of reads it back in-process. Nothing here converts: a driver reports in exactly the annotated unit.

    A bare unit with no quantity (a config field like frequency_hz) still wants UnitRef; a driver's typed alias for a named quantity is shorter as Annotated[float, FLOW], a Quantity standing directly as its own metadata -- see Quantity's own pydantic hook. unit_of finds either.

    UnitRef ¶

    Annotated metadata: the unit a float is reported in.

    Pydantic puts it in the field's JSON schema; get_type_hints(cls, include_extras=True) finds the object in-process.

    Measured ¶

    Measured(unit: Unit, /, **constraints: Any) -> Any

    A float annotated with the unit it is reported in.

    Keyword arguments are pydantic Field constraints: Measured(Litre / Minute, ge=0) also puts minimum: 0 in the schema. Returns Any, so it defeats a type checker; prefer the typed form, Annotated[float, QUANTITY] with a Quantity, where one applies.
