    flyball.adaptive¶

    Identifying a plant while it runs, and retuning from what is found.

    Identifier tracks a discrete model of a loop from its samples; SelfTuner watches it drift and says when a retune is warranted. Neither writes to a loop: the caller hands the gains over, so a retune takes the same bumpless path as any tuning change.

    A loop is a controlled quantity, a manipulated one and any measured disturbances, named by Schema; nothing here knows what is controlled.

    schema = Schema(controlled=process, manipulated=demand, disturbances=(supply,))
identifier = Identifier(schema, interval=1.0, delay_samples=4)
tuner = SelfTuner(identifier, rule=imc)

# every tick
identifier.push(Sample(reading.value, loop.demand, (supply_reading.value,)))
tuner.observe(identifier.residual)
tuner.elapsed(interval)

# on a much slower clock
retune = tuner.consider()
if retune.offered:
    loop.regulate(ValueSource.SETPOINT, tuning=tuner.accept(retune.plant),
                  transfer=Transfer.TRACK)

    The model is ARX because it is linear in its parameters, so the estimate can recurse; Arx.plant gives the continuous form. Updates are gated on excitation. Dead time is not identifiable by recursion, so it comes from calibration.

    RecursiveLeastSquares ¶

    Tracks the parameters of a model that is linear in them.

    Plain lists, not arrays: regressors are a few terms wide and the estimator stays dependency-free.

    Parameters:

    Name Type Description Default

    How many parameters; every regressor must match.

    		 required
    forgetting NormalisedPositive

    How fast old samples lose weight. One never adapts; lower tracks drift faster and follows noise further.

    		 0.98
    covariance Positive

    Initial diagonal. Large means "no idea yet".

    		 1000.0
    covariance_limit Positive

    Trace above which the covariance is rescaled, so it cannot grow without bound during a lull in excitation.

    		 100000000.0

    SelfTuner ¶

    Watches a model drift and offers a new tuning when warranted.

    Runs on a much slower clock than the identifier: retuning faster than the plant settles makes the two loops interact, so settling_periods is a floor. Applies nothing; the caller derives gains and hands them over, so a retune takes the same bumpless path as any tuning change.

    Parameters:

    Name Type Description Default
    identifier Identifier

    The estimator to read.

    		 required
    rule Callable[[Plant], T]

    Turns a plant into the caller's tuning type.

    		 required
    bounds Bounds | None

    What counts as a plausible plant.

    		 None
    drift Positive

    Fractional change in gain or time constant worth retuning for.

    		 0.15
    settling_periods PositiveInt

    Minimum retune spacing, in time constants of the model in force.

    		 5
    residual_growth Positive

    Ratio of current to best residual above which the model no longer describes the plant.

    		 3.0

    Arx dataclass ¶

    A discrete first-order model with input delay.

    y[k] = a*y[k-1] + b*u[k-d] + sum(c[i]*w[i][k]). Linear in its parameters, which lets the estimator recurse. plant gives the continuous form.
