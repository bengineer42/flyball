    flyball.client¶

    A client for a running rig, built from the schema it publishes. See flyball.client.rig.

    flyball.client.rig ¶

    A client for a running rig, built from the schema it publishes.

    Rig fetches /api/schema once and synthesises a method per device command, validating arguments against the schema before sending:

    rig = Rig("http://pi:8000")
rig.devices.pumps.set_fraction(wet_fraction=0.25, flow={"tag": "absolute", "flow": 8})
rig.devices.sht4x.view()["conditions"]
rig.demand("heaters.heater1", 1200.0)
for frame in rig.watch("controllers"):
    ...

    The CLI is this with argparse in front.

    flyball.client.validate ¶

    Enough JSON Schema to check a command's arguments before sending them.

    Covers what the server's argument schemas use: objects, required, scalar types, enum and oneOf of constants, bounds, anyOf, $ref into $defs, null. Errors say where and why in the schema's terms.
